# Commande kebab de la team

Petit site de commande groupée (naan, galette, tacos, assiette).

- `index.html` : page de commande pour l'équipe
- `admin.html` : vue organisateur (protégée par mot de passe)
- `menu.js` : menu, prix et configuration Supabase

Hébergement : GitHub Pages. Données : Supabase (accès uniquement via fonctions RPC).
